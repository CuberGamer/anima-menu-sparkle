## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Ejecutar el proyecto en Visual Studio Code

1. Instala [Node.js 20+](https://nodejs.org) y abre la carpeta del proyecto en VS Code.
2. Acepta las extensiones recomendadas (ESLint, Prettier, Tailwind CSS).
3. En la terminal integrada:

```sh
npm install
npm run dev
```

4. Abre `http://localhost:8080`. Tambien podes usar **Run and Debug → Dev server (npm run dev)** o las tareas `dev` / `build` / `lint` (Ctrl+Shift+P → *Run Task*).

Comandos utiles:

| Comando | Que hace |
| --- | --- |
| `npm run dev` | Servidor de desarrollo con recarga en caliente |
| `npm run build` | Build de produccion |
| `npm run preview` | Sirve el build de produccion |
| `npm run lint` | Revisa el codigo con ESLint |

El juego se juega en `/tablero` y el menu principal esta en `/`.
